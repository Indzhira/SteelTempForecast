# SteelTempForecast: предсказание температуры сплава для снижения энергопотребления на металлургическом производстве

**Цель:** помочь металлургическому комбинату снизить потребление электроэнергии за счёт более точного контроля теплового режима.

Модель позволяет прогнозировать температуру на основе технологических параметров (время нагрева, подача материалов, измерения и т. п.) и тем самым заранее выявлять отклонения, требующие корректировки.

## Бизнес-ценность
* **Снижение энергозатрат и времени плавки.** Прогноз финальной температуры позволяет заранее понимать риск недогрева/перегрева и корректировать параметры.
* **Стабилизация качества продукции.** Контроль температуры снижает риск отклонений от требуемых свойств сплава, а значит и уменьшает долю брака.
* **Основа для дальнейшей оптимизации.** Модель может стать базой для внедрения системы поддержки принятия решений.

## Данные
**Источник:** Яндекс Практикум (учебный датасет)

**Описание:** Данные хранятся в Sqlite, которая состоит из нескольких таблиц:
* `steel.data_arc` — данные об электродах;
* `steel.data_bulk` — данные об объёме сыпучих материалов;
* `steel.data_bulk_time` — данные о времени подачи сыпучих материалов;
* `steel.data_gas` — данные о продувке сплава газом;
* `steel.data_temp` — данные об измерениях температуры;
* `steel.data_wire` — данные об объёме проволочных материалов;
* `steel.data_wire_time` — данные о времени подачи проволочных материалов.

## Постановка задачи

**Целевая переменная:** финальная температура сплава.
**Тип задачи:** регрессия.
**Метрика качества:** `MAE`, т.к. она интуитивно понятна для производства.

Для решения задачи использованы ансамблевые методы и нейросеть:
* `RandomForestRegressor` - надёжная базовая модель, устойчивая к выбросам.
* `XGBRegressor` и `LGBMRegressor` - градиентный бустинг для максимальной точности.
* `Нейросеть` - альтернативный подход для проверки дает ли нелинейная модель прирост.
* `DummyRegressor` - константная модель.

**Ключевые этапы работы**
* Загрузка данных: данные загружаются из SQL‑базы.
* Предобработка и EDA.
* Подготовка данных.
* Подбор гиперпараметров, обучение моделей. 
* Сравнение и тестирование модели, оценка влияния признаков на прогноз.
* Выводы и рекомендации.

## Результаты
**Лучшая модель:** `LightGBM.`

**Метрика качества:** `MAE = 6.39` на тестовой выборке, что на 1.89 лучше константной модели.

**Ключевые факторы влияния на финальную температуру:**

* время нагрева электродов;
* начальная температура;
* интервал между замерами температуры.

Эти признаки согласуются с физикой процесса и дают технологическую интерпретацию.
